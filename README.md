# SWANA
### Smart Web Analytics & Narrative Assistant

SWANA is an AI-powered data analysis application built with Python and Streamlit. It allows users to upload CSV or Excel datasets, explore their structure, clean their data, and perform statistical analysis using natural-language commands.

Instead of writing Python or SQL queries, users can ask questions such as:

- What is the average salary by department?
- How many employees work in IT?
- What is the total salary for Finance?
- Remove duplicate rows.
- What is the average unit price by category?

SWANA uses a large language model (LLM) to translate natural-language requests into structured JSON commands. These commands are validated and executed using predefined Python functions and pandas.

The LLM interprets user intent but does not generate or execute arbitrary Python code.

## Features

### Natural-Language Data Analysis

SWANA allows users to analyze uploaded datasets using everyday language.

Supported statistical operations include:

- Average
- Sum
- Count
- Minimum
- Maximum
- Median

The application supports regular, grouped, and filtered analysis.

For example, users can calculate the average salary across an entire dataset, compare average salaries by department, or calculate the average salary for a specific department.

Text filtering is case-insensitive and ignores surrounding whitespace.

### AI-Powered Command Generation

SWANA uses the Groq API with the `openai/gpt-oss-20b` model to convert natural-language requests into structured JSON commands.

For example, the question:

"What is the average salary of the IT department?"

Can generate the following command:

```json
{
  "operation": "average",
  "column": "annual_salary",
  "filter": {
    "column": "department",
    "value": "IT"
  }
}
```

The generated command is validated before execution.

The command parser checks supported operations, required parameters, filters, grouping rules, and incompatible command combinations.

The dispatcher then routes validated commands to predefined Python functions.

SWANA does not execute arbitrary Python code generated by the LLM.

### Data Cleaning

SWANA provides data-cleaning functionality through natural-language commands and dedicated interface controls.

Supported cleaning operations include:

- Remove duplicate rows
- Remove rows containing missing values
- Fill missing values in a specified column
- Remove completely empty columns
- Standardize column names

Cleaning operations modify the application's working dataset while preserving the original uploaded data.

Users can restore the original dataset using the Reset Dataset button.

### Dataset Exploration

After uploading a dataset, SWANA provides an overview containing:

- Total rows and columns
- Missing values
- Duplicate rows
- Numeric and text column counts
- Column names and data types
- Dataset preview
- Descriptive statistics for numeric columns

The data-quality section identifies missing values and duplicate records.

### Data Visualization

SWANA can visualize grouped analysis results using:

- Bar charts
- Line charts
- Area charts

Users can switch between visualization types and download grouped analysis results as CSV files.

### Data Export

SWANA allows users to download:

- The current working dataset after cleaning
- Grouped analysis results

The original uploaded dataset remains available for resetting the application.

### Generated Command Transparency

Users can expand the View Generated Command section to inspect the validated JSON command produced from their natural-language request.

This makes it easier to understand how SWANA interpreted a question and which operations were executed.

## Architecture

SWANA separates natural-language interpretation from data execution.

```text
                 User
                  |
                  v
         Streamlit Interface
                  |
          +-------+-------+
          |               |
          v               v
     File Upload    Natural-Language
          |             Request
          v               |
     CSV / Excel          |
          |               |
          v               |
     pandas DataFrame     |
          |               |
          v               v
     Available        Groq LLM API
     Columns ------------>|
                          |
                          v
                    JSON Command
                          |
                          v
                  Command Validation
                          |
                          v
                      Dispatcher
                          |
                 +--------+--------+
                 |                 |
                 v                 v
            Data Cleaning     Data Analysis
                 |                 |
                 |          +------+------+
                 |          |             |
                 |          v             v
                 |       Standard      Grouped /
                 |       Analysis      Filtered
                 |          |             |
                 |          +------+------+
                 |                 |
                 v                 v
          Updated Dataset       Results
                 |                 |
                 v          +------+------+
          Dataset Preview   |             |
                            v             v
                         Tables         Charts
```

### How the Architecture Works

1. The user uploads a CSV or Excel dataset through Streamlit.
2. SWANA loads the dataset into a pandas DataFrame.
3. The user enters a natural-language question or cleaning request.
4. The available column names and user request are sent to the Groq API.
5. The LLM generates a structured JSON command.
6. The command parser validates the operation and its parameters.
7. The dispatcher routes the validated command to the appropriate Python function.
8. SWANA displays the analysis result or updates the working dataset.

The execution layer uses predefined Python functions rather than arbitrary LLM-generated code.

This separation makes SWANA's calculations independently testable and reduces the risks associated with executing AI-generated instructions.

## Installation

### Prerequisites

- Python 3.11 or later
- pip
- A Groq API key

### 1. Clone the Repository

```bash
git clone https://github.com/AlyaanMir45/SWANA.git
cd SWANA
```

### 2. Create a Virtual Environment

Windows PowerShell:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

macOS or Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Install Dependencies

Install the required Python packages:

```bash
python -m pip install streamlit pandas openpyxl xlrd openai python-dotenv pytest
```

### 4. Configure the Groq API Key

Create a `.env` file in the project root.

Add the following environment variable:

```env
GROQ_API_KEY=your_groq_api_key_here
```

A Groq API key can be obtained from:

https://console.groq.com/

Never commit your `.env` file or API key to GitHub.

### 5. Run SWANA

Start the Streamlit application:

```bash
python -m streamlit run app.py
```

Streamlit will provide a local URL, typically:

http://localhost:8501

Open the URL in your browser.

## How to Use

### Upload a Dataset

Upload a CSV or Excel file through the Streamlit interface.

SWANA will display the dataset's structure, quality information, and preview.

### Ask a Question

Enter a natural-language question in the Ask SWANA section.

Example:

"What is the average salary by department?"

Click Run Command to generate and execute the analysis.

### Review the Results

SWANA displays the calculated result as a metric or grouped-analysis table.

For grouped analysis, users can select a bar, line, or area chart.

The View Generated Command section displays the validated JSON command used for the calculation.

### Clean the Dataset

Use the Data Cleaning section or a supported natural-language command to clean the uploaded dataset.

Available interface controls include removing duplicate rows, removing rows with missing values, removing empty columns, and standardizing column names.

### Reset or Download

Click Reset Dataset to restore the original uploaded dataset.

Download the current working dataset or grouped analysis results as CSV files.

## Security and Validation

SWANA uses a controlled execution architecture.

The LLM generates structured JSON commands rather than executable Python code. The command parser validates the requested operation, required parameters, grouping rules, and filters before execution.

Unsupported operations and malformed commands are rejected.

The dispatcher executes supported operations using predefined pandas functions.

API credentials are loaded through environment variables.

SWANA sends user requests and available column names to the external LLM provider. Dataset rows are processed locally by pandas in the current implementation.

Users should still review applicable privacy and data-handling requirements before using sensitive datasets.

## Limitations

SWANA v1 has several intentional limitations:

- Supports CSV and Excel files rather than direct database connections.
- Supports one equality filter per command.
- Does not currently support multi-step conversational follow-up questions.
- Supports a predefined set of statistical and cleaning operations.
- Requires an internet connection and a configured Groq API key for natural-language commands.
- AI-generated commands may occasionally require users to rephrase their requests.

The restricted command format is intentional and limits the operations that can be executed against uploaded datasets.
